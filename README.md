# AI Chat Assistant

A full-stack chat assistant: React (Vite) client, Express API, MongoDB for history, and Groq-hosted LLMs with streamed replies.

## Features

- Streaming replies (Server-Sent Events) with a **Stop** button; partial replies are kept and marked as unfinished
- Conversation history stored in MongoDB, grouped into Today / Earlier with relative times; click the header title to rename, delete with confirmation
- Automatic conversation titles generated by a small, fast model
- Tone toggle (Professional / Casual / Concise) applied server-side as a system instruction; each reply shows its tone
- Follow-up question chips under the latest reply
- Markdown rendering with tables, syntax-highlighted code blocks and copy buttons
- Light and dark themes (follows the system until you pick one; code blocks stay dark), Manrope + JetBrains Mono, lucide icons, with 44px touch targets and a slide-out sidebar on mobile

## Setup

Requires Node.js 20+.

```bash
npm install
npm install --prefix server
npm install --prefix client
cp server/.env.example server/.env   # then fill in the values
npm run dev
```

The client runs on http://localhost:5173 and proxies `/api` to the server on port 5000.

### Environment variables (`server/.env`)

| Variable | Description |
|---|---|
| `PORT` | API port (default `5000`) |
| `MONGODB_URI` | MongoDB connection string |
| `DNS_SERVERS` | Optional. Comma-separated DNS servers for Node, e.g. `8.8.8.8,1.1.1.1`. Set this if `mongodb+srv://` fails with `querySrv ECONNREFUSED` |
| `GROQ_API_KEY` | Groq API key ([console.groq.com](https://console.groq.com)) |
| `CHAT_MODEL` | Model for replies (default `openai/gpt-oss-120b`) |
| `UTILITY_MODEL` | Model for titles (default `openai/gpt-oss-20b`) |
| `CLIENT_ORIGIN` | Allowed CORS origin |
| `MAX_CONTEXT_MESSAGES` | How many recent messages are sent to the model |
| `MAX_MESSAGE_LENGTH` | Maximum characters per user message |

## API

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/health` | Server and database status |
| `GET` | `/api/config` | Client settings (max message length) |
| `GET` | `/api/meta` | `{ modelLabel }`, e.g. `openai/gpt-oss-120b via Groq` |
| `GET` | `/api/tones` | Available tones: `[{ id, label, description }]` |
| `GET` | `/api/conversations` | List conversations, newest first, each with `messageCount`, `group` (`Today` / `Earlier`), `relativeTime` and `startedTime` labels computed on the server |
| `POST` | `/api/conversations` | Create a conversation |
| `GET` | `/api/conversations/:id` | Conversation with its messages and `messageCount` |
| `PATCH` | `/api/conversations/:id` | Rename (`{ "title": "..." }`) |
| `DELETE` | `/api/conversations/:id` | Delete a conversation and its messages |
| `POST` | `/api/conversations/:id/messages` | Send `{ "content": "...", "tone": "professional" }` (`tone` optional, `400` if unknown); replies as an SSE stream of `user`, `delta`, `done` and `error` events |

## Project structure

```

  api.js                 REST helpers and SSE stream reader
  App.jsx                App state: conversations, streaming, errors
  components/            Sidebar, ChatHeader, ChatView, Composer, ToneToggle, Markdown, ErrorBoundary
server/src/
  server.js              Connects to MongoDB, starts the API
  app.js                 Express app and middleware
  config/db.js           MongoDB connection
  models/                Conversation and Message schemas
  prompts/tones.js       Tone definitions and system prompt modifiers
  routes/conversations.js
  utils/time.js          Relative time and Today/Earlier labels
  services/llm.js        Groq streaming chat, titles and follow-up questions
  middleware/errors.js
```
